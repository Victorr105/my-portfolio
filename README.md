# my-portfolio
This is a school project for my portfolio

 Portfolio

A personal portfolio website showcasing my work, skills, and background as a software developer. Built with plain HTML and CSS — no frameworks, no build tools, just clean hand-written code.

## Features

Responsive design — adapts smoothly across desktop, tablet, and mobile screens with breakpoints at 1200px, 992px, 768px, 575px, and 320px.


Sticky black navigation bar with orange hover accents.

Hero section  with profile image, introduction, and call-to-action buttons.
About section covering intro, skills, and education inside a clean white card.
Projects section with a "work in progress" placeholder.
Contact section with clickable cards linking to Email, GitHub, and LinkedIn.
Dark + orange theme  used consistently throughout.

## Tech Stack

HTML5 — semantic structure with sectioning and accessibility in mind.
CSS — flexbox layouts, custom media queries, box shadows, gradients, and hover transitions.
